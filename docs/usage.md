# 使用说明与最佳实践

## 概述

本文档旨在帮助电教管理员和教师快速上手 Awesome Iwb 推荐清单中的各类软件，并分享社区积累的最佳实践经验。

## 快速上手

### 新班级开学部署清单

如果你的班级一体机是全新环境，建议按以下顺序部署：

1. **基础环境**
   - 安装 .NET Framework 4.8 及以上版本
   - 安装 Visual C++ 可再发行组件包（含 x86 和 x64）

2. **核心软件**
   - 安装一款屏幕批注工具（推荐 ICC-CE 或 Ink Canvas Plus）
   - 安装一款课表软件（推荐 ClassIsland）
   - 配置开机自启

3. **辅助软件**（按需）
   - 随机点名工具
   - 考试看板（考前配置）
   - 视频展台工具

4. **优化调整**
   - 设置各软件窗口位置
   - 配置快捷键
   - 测试触控响应

## 各场景最佳实践

### 日常上课

- **课前**：确保批注工具和课表软件已在后台运行
- **课中**：使用批注工具的 PPT 联动功能进行板书
- **课后**：无需关闭软件，保持后台运行即可

### 考试场景

- **考前1天**：提前部署考试看板，导入考试信息
- **考前30分钟**：启动考试语音播报系统（如适用）
- **考试期间**：保持考试倒计时显示
- **考试结束后**：关闭考试相关软件

### 公开课 / 展示课

- 使用 ICC-CE 或 ppInk 的高级批注功能
- 开启白板模式进行板书展示
- 配合 ShowWrite 进行实物展台展示

## 标签体系说明

本项目使用统一的标签体系对软件进行分类，所有标签来源于 `_data/project.json` 中的 `tags` 数组。以下是主要标签的含义：

| 标签 | 含义 |
|------|------|
| 屏幕批注 | 在任意屏幕内容上进行标注 |
| 桌面批注 | 在桌面上直接进行书写 |
| PPT批注 | 与 PowerPoint 联动进行批注 |
| 白板软件 | 提供虚拟白板功能 |
| 课程表 | 显示班级课程安排 |
| 看板 | 信息展示类面板 |
| 随机点名 | 随机抽取学生姓名 |
| 课堂互动 | 增强师生互动的工具 |
| 教学辅助 | 辅助教学的各类工具 |
| 闭源 | 非开源但免费使用的软件 |
| 停更 | 已停止维护的项目 |

## 数据驱动说明

Awesome Iwb 的软件数据统一存放在 `_data/project.json` 中。这意味着：

- **查看数据**：直接打开 JSON 文件即可获取所有项目信息
- **修改数据**：编辑 JSON 后，所有引用该数据的地方自动同步
- **程序化访问**：其他工具或网站可以通过读取 JSON 获取项目列表
- **标签一致性**：所有标签均来自 JSON 中的 tags 数组，避免硬编码导致的不一致
