# 使用指南

## 快速上手

### 1. 选择适合的软件组合

不同班级场景对应不同的软件需求，建议按以下组合使用：

| 场景 | 推荐组合 |
|------|---------|
| 日常上课 | 课表软件 + 屏幕批注工具 |
| 考试期间 | 考试看板 + 倒计时工具 |
| 班会活动 | 随机点名 + 互动工具 |
| 公开课 | 屏幕批注 + PPT辅助 + 视频展台 |

### 2. 阅读项目文档

每个项目在其 GitHub 仓库中都有详细的 README 和使用说明。使用前请务必阅读。

## 分类导航

### 屏幕批注与白板

在屏幕上直接书写、标注，支持 PPT 联动。适合日常授课时在课件上做标记、画图演示。

### 课程管理

展示班级课表、作息时间等信息。部分软件支持自定义铃声、换课提醒等高级功能。

### 信息展示与看板

在大屏上展示班级信息，包括作业公示、考试安排、倒计时、热搜排行等内容。

### 课堂互动

用于活跃课堂气氛，包括随机点名、抽奖、小组计分等互动功能。

### 系统工具与辅助

一体机系统层面的增强工具，如自动化登录、截图录屏、视频展台、PPT触屏翻页辅助等。

## 常见问题

### 软件安装后重启就消失了？

学校的希沃一体机大多开启了冰点还原/硬盘保护。请联系电教管理员关闭保护，或将软件安装在不受保护的盘符。

### 软件闪退/报错？

- 确认系统已安装必要的运行库（.NET Framework、VC++ Redistributable 等）
- 尝试以管理员权限运行
- 查看项目的 GitHub Issues 页面是否有类似问题

### 如何让软件开机自启？

- 大多数推荐软件在设置中内置了"开机启动"选项
- 或手动将快捷方式放入 `shell:startup` 文件夹
