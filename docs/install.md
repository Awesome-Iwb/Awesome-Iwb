# 安装与配置指南

## 概述

Awesome Iwb 是一个软件推荐清单和实用知识手册，本身不是一个可安装的应用程序。本指南将帮助你了解如何在班级一体机上部署和使用推荐列表中的软件。

## 基本要求

### 设备要求

- 希沃/鸿合等班级教学一体机
- Windows 7 及以上操作系统
- 建议配备触控屏或数位板以获得最佳体验

### 软件选择建议

在安装任何软件之前，请注意以下几点：

1. **查看软件状态**：优先选择标记为「活跃」的项目，谨慎使用「停更」项目
2. **阅读原始文档**：每个项目都应查阅其官方 README 或文档
3. **测试兼容性**：在一体机上安装前，建议先在测试环境中验证

## 分类安装指引

### 屏幕批注与白板

屏幕批注类软件需要管理员权限以实现在屏幕顶层绘制。推荐安装流程：

1. 从项目 GitHub Releases 页面下载最新版本
2. 以管理员身份运行安装程序
3. 根据项目文档完成初始配置
4. 测试 PPT 联动和快捷白板功能

**推荐搭配**：
- 日常使用：ICC-CE 或 Ink Canvas Plus
- 高性能需求：智绘教 Inkeys
- 视频展台：ShowWrite

### 课表与日常看板

课表类软件通常需要设置开机自启：

1. 下载并安装软件
2. 导入或手动配置课表数据
3. 在设置中开启「开机自启」选项
4. 调整窗口位置和大小以适应屏幕

**推荐首选**：ClassIsland（使用人数最多，生态最完善）

### 考试专题工具

考试工具建议在考前提前配置：

1. 安装考试看板软件
2. 导入考试科目、时间、考场等信息
3. 测试语音播报功能（如适用）
4. 确保倒计时显示正确

### 随机点名与抽选

随机点名工具一般开箱即用：

1. 下载并启动软件
2. 导入班级学生名单
3. 根据需要调整抽取规则

### 教学辅助工具

辅助类工具种类繁多，按需选择：

- **希沃定制启动器**：优化一体机启动流程
- **自动登录工具**：简化日常登录步骤
- **屏幕锁定工具**：防止误触

## 常见问题

### 软件无法正常运行

1. 检查是否以管理员身份运行
2. 确认 .NET Framework / Visual C++ 运行时已安装
3. 查阅项目 Issues 页面

### 一体机触控不灵敏

1. 在软件设置中调整触控灵敏度
2. 部分软件提供「边缘手势屏蔽」选项，建议开启
3. 确保一体机驱动为最新版本

### 软件开机自启失败

1. 检查是否被安全软件拦截
2. 将软件添加到杀毒软件白名单
3. 手动添加快捷方式到启动文件夹
