# 安装与部署

本清单中收录的软件均为独立运行的应用，不存在统一的安装流程。以下按平台给出通用指引。

## Windows（希沃/鸿合一体机）

绝大多数一体机运行 Windows 系统，直接下载 `.exe` 或 `.msi` 安装包运行即可。

### 典型安装步骤

1. 从对应项目的 GitHub Releases 页面下载最新版本
2. 运行安装程序，按向导完成安装
3. 根据需要配置开机自启（多数软件内置此选项）

### 常见一体机型号说明

| 品牌 | 系统 | 架构 | 备注 |
|------|------|------|------|
| 希沃 | Windows 10/11 | x64 | 通常有还原精灵，需注意 |
| 鸿合 | Windows 10 | x64 | 部分机型带硬盘保护 |
| 其他品牌 | Windows | x64 | 视具体型号而定 |

### 一体机特别注意事项

- 部分学校一体机开启了硬盘还原/冰点还原，安装软件前请先确认
- 如需持久化安装，请联系学校电教管理员关闭还原保护
- 推荐将软件安装在非系统盘以避免被还原

## 绿色软件 / 便携版

部分软件提供免安装的便携版，解压后直接运行即可，适合有还原保护的设备：

- 将软件放置于 `D:\Tools\` 等非系统盘目录
- 创建桌面快捷方式方便日常使用

## 远程部署

对于管理多台一体机的电教老师，可考虑：

- 使用局域网共享分发安装包
- 编写批处理脚本批量静默安装
- 通过班班通管理平台统一推送
